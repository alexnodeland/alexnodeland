## About the role

A senior applied AI engineer on the agent capabilities team of a consumer-scale AI answer and agent company. The team is typically first to evaluate new frontier models, work out where they create real user value, and turn them into reusable, reliable agent capabilities for both end users and other agents. The role has broad ownership across frontier model evaluation, agent systems, platform engineering and product. Stated stack: Python, Go, Rust, PostgreSQL, DynamoDB, AWS, TypeScript.

## Responsibilities

- Benchmark frontier models on real user tasks, catalogue useful behaviours and failure modes, and productionise the most promising ones as agent systems, owning prototyping, evaluation, launch, monitoring and iteration
- Improve agent planning, tool use, context management, error recovery and reliability on long-running tasks
- Apply current ML and LLM techniques to build scalable agent capabilities such as skills, plugins, artifact generation, tool integration, automated research and multi-agent collaboration, and shape the abstractions and product experiences around them
- Own agent behaviour end-to-end from user-facing interfaces to backend services
- Define offline and online evaluations covering task completion, correctness, safety, latency, cost and user satisfaction, and iterate across models, prompts, harnesses and products
- Build secure, observable agent systems, including permissions and safeguards for sensitive actions
- Develop tracing, replay and monitoring infrastructure so agent failures are reproducible and actionable
- Partner with product management, data science and research on high-impact opportunities in emerging model capabilities
- Set technical direction on ambiguous problems through design reviews, mentorship and technical leadership

## Required qualifications

- Typically 6+ years of professional software engineering, including building and owning robust AI-powered, large-scale, user-facing or data-intensive products (exceptional candidates with less experience considered)
- Strong engineering fundamentals and experience operating AI/ML products, backend services or distributed systems at scale
- Experience owning the AI product lifecycle: data analysis, rigorous evaluation, production monitoring, metric definition and iteration from production data and user feedback
- Practical experience in areas such as agent harnesses, tool use, context engineering, model evaluation, browser automation or long-running task execution
- Strong product judgment in turning ambiguous user needs into applied AI/ML problems with measurable impact
- Genuine interest in rapidly exploring, evaluating and productising new model behaviours

## Preferred qualifications

- LLM context engineering or harness engineering; work with subagents, coding assistants, or long-running / autonomous task execution
- Deep familiarity with strengths and weaknesses of current model families in reasoning, tool use, context management and long-horizon tasks
- Experience building agent permissions, safeguards, evaluation infrastructure or production observability
- Experience with mid-training, post-training or reinforcement learning on frontier or open-source models
- AI/ML research track record via publications or open-source contributions
- Time at a fast-growing startup or high-ownership engineering team
