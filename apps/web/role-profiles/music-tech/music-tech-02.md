## About the role

A senior machine learning engineering role on the recommendations group of an audio streaming platform with a large catalogue of uploaded tracks. The role centres on ML-driven features that lift personalisation, engagement and listener satisfaction, and it is deliberately full-stack: the engineer owns features from data pipelines through APIs to real-time serving, working with very large event datasets and collaborating closely with product, design and platform colleagues.

## Responsibilities

- Develop, test and productionise ML and LLM-based systems that serve live users
- Design and build complete ML pipelines covering data, features, training and serving
- Weigh cost, latency, complexity and maintainability when making technical calls
- Work across distributed data systems such as BigQuery, BigTable, Airflow and DynamoDB to build reliable, scalable solutions
- Put monitoring, A/B testing and metrics frameworks in place to measure genuine user impact
- Debug hard problems spanning data pipelines, ML models and distributed systems
- Contribute to the team's technical strategy and engineering practices
- Use agentic workflows and AI-assisted engineering to multiply delivery speed

## Required qualifications

- 1-2+ years building ML systems in production, with a clear sense of the gap between a notebook model and one serving millions of users
- 4+ years of software engineering experience writing production code rather than notebooks alone
- Strong Python and Scala (or another JVM language such as Java), used for scalable production code
- Experience building and deploying ML models end to end across data, training, serving and monitoring
- Experience putting LLM-based features into production
- Familiarity with integrating LLMs into ML systems, for example retrieval-augmented generation and model serving
- Understanding of ML architecture shared across domains such as search and recommendations
- A strong focus on correctness and on data quality, with awareness of the way upstream data shapes downstream models
- Strong SQL over very large datasets using BigQuery and Spark
- Cloud platform experience (AWS/GCP) plus containerisation with Docker and Kubernetes
- Experience with distributed data processing and ETL pipelines using Airflow and Spark
- Familiarity with ML frameworks such as TensorFlow or PyTorch
