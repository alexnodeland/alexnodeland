## About the role

A senior engineer on the forward deployed team of an enterprise AI platform company, working directly with strategic enterprise customers to architect, integrate, deploy and operate production AI agent systems. The role combines software engineering, distributed systems, cloud infrastructure and frontier AI to turn models into dependable enterprise software, spanning agent architecture, customer-system integration, AI quality and technical leadership on accounts. Engineers are expected to grow expertise in both forward deployed engineering and applied AI over time.

## Responsibilities

- Architect and deploy production AI systems that integrate with complex enterprise environments: cloud platforms, data warehouses, internal APIs, business applications and proprietary systems.
- Design scalable agent architectures combining LLMs, retrieval, memory, tools, structured knowledge and enterprise data.
- Build secure integrations that let agents act on customer systems while meeting security, governance and compliance requirements.
- Prototype new AI capabilities quickly and harden successful prototypes into production systems.
- Build agent runtimes, orchestration frameworks, context pipelines, execution services and tool integrations.
- Build in retries, fallback strategies and graceful degradation, and engineer for reliability, latency, scalability and observability.
- Create human-in-the-loop flows where experts oversee AI automation, plus deployment patterns that allow continuous delivery and experimentation.
- Stand up evaluation harnesses (golden datasets, regression suites, offline benchmarks, online experiments, LLM-as-a-Judge) that catch quality regressions before customers see them.
- Implement tracing, observability, monitoring, guardrails, grounding and safety mechanisms for production agents.
- Evaluate newly released models, agent frameworks, evaluation methods and developer tools for safe production adoption.
- Act as primary technical advisor on strategic accounts, lead architecture discussions, and document reusable architecture and deployment patterns.

## Required qualifications

- 5+ years as a software engineer, with solid grounding in system design, distributed systems, algorithms and data structures.
- Strong Python skills and experience building production software.
- Has built or shipped AI-powered applications with some of: vector databases, retrieval systems, MCP, agent frameworks, modern LLM APIs.
- Hands-on with a major cloud (AWS, Azure or GCP) and current production infrastructure practices.
- Strong problem solving under ambiguous requirements, iterating quickly toward production.
- Excellent communication and ability to work directly with enterprise engineering teams.

## Preferred qualifications

- Has deployed production AI agents or autonomous systems.
- Has designed distributed systems, APIs, orchestration services or large-scale backends.
- Experience with cloud-native infrastructure: Docker, Kubernetes, Infrastructure as Code and CI/CD.
- Has integrated AI systems into enterprise software environments.
- Familiar with agent design: tool use, retrieval, memory and context engineering.
- Experience with tracing, LLM observability, AI monitoring, regression testing and evaluation frameworks.
- Has implemented guardrails, grounding and safety mechanisms for production AI.
- Has operationalized new foundation models, agent frameworks or AI infrastructure.
- Direct enterprise customer experience, including leading architecture reviews, technical workshops or design sessions.
